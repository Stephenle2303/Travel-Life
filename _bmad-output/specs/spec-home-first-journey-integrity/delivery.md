## Vietnam regional label safeguard

The offline resolver's bundled Vietnam Admin-1 boundaries are known to
misclassify public reference points. Until validated replacements are available,
`resolveDestination` returns a supported country with no region for Vietnam.
This is an expected unavailable region outcome, not a runtime failure.
It adds no fallible I/O boundary. Existing durable destination query and
computation diagnostics remain responsible for real failures. Regression
controls exercise public Sa Dec and Can Tho points through both the resolver
and the committed evidence title formatter, with Bali as an unaffected control.
