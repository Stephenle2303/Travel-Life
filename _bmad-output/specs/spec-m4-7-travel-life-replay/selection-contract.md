# Replay selection and evidence contract

## Private Replay and curated chapters

One Replay action uses the current policy-visible Journey List and active opaque
scope from Atlas; otherwise use the full list. Retain every scoped eligible trip,
including manual/inferred records with provenance. Build a adaptively timed curated chapter
per trip, using timing-contract.md, not a full-media contact sheet. Total playback grows with the trip list;
no25-panel/global60s scope-narrowing rule remains. Preserve Atlas return context.

Use shared album membership/access primitives, not a second independent scope
query. Privacy/corrections remain hard gates; read/access failure is never empty
history. All effective attached assets, including undated/GPS-less items, enter
the candidate ledger. Exclude suggested/rejected/unassigned/ambiguous associations
from eligible inputs. Respect current read access and original decode separately;
unknown stored availability is resolved, not treated as unusable.

Use Journey List order and precision for trips until owner presentation overrides.
Capture-time/event diversity within a trip preserves known precision; unknown dates
are not manufactured. No selected image or model output proves owner presence,
travel duration, route or new trip membership. Exact-date media filters still
require known intervals wholly within scope and disclose unknown/boundary exclusions.

Page at60 candidates/read with stable identity/order and generation checks. Keep
source references below provider/repository/native boundaries. Cloud-only, denied,
missing, unsupported, oversized and decode-failed outcomes remain fixed and distinct;
no automatic cloud download or permission prompt.

## Automatic memory selection and private editing

memory-selection-contract.md defines the staged selector and timing: respect
Keep/Exclude, group near-duplicates, balance trip events/visual variety and usable
quality, and use optional consented AI for ambiguous visual decisions. Aesthetic
score alone is insufficient. No mandatory review/curation precedes private watching.
Not selected is normal editorial curation; do not delete media or label it missing.

Private Edit begins with the chosen storyboard. Offer Replace/Add/Remove/Reorder;
persist internal Keep/Exclude/Auto intent and ordering and working/committed revisions per interaction-contract.md. Recompute
only affected chapters. Explicit keeps cannot bypass hard privacy gates; excessive
keeps may extend that chapter rather than be dropped. Ordinary Replay reuses the
same versioned selection instead of randomly reshuffling memories.

## Separate exact selected export

Share opens a separate empty-first trip/chapter selection with select-all and
individual chosen-shot controls. Selecting a trip selects its current curated
chapter, not every album asset. Offer optional additional eligible memories;
manual additions enter Keep semantics and exact timing. Show chosen source-media
and technical/editorial counts without forcing an explanation wizard. No private
draft or cached preview automatically grants export/publish approval.

Exported inferred facts require current owner confirmation through
loadJourneyEligibility(...,'share',expectedPrivacyRevision) and existing correction
flow; a Replay checkbox is not journey confirmation. Selection/confirmation changes
invalidate old output/review. Assemble and play the exact export-mode chapter
sequence, bind its verified bytes/digest to the immutable manifest, require explicit
review and Export, then revalidate dispatch. Never silently rerender at handoff.

Long chosen export uses measured local storage/streaming assembly; no fixed global
32MiB/60s cap or silent sampling. Resource failure retains the selection and explains
retry/storage recovery. Hosted highlight attachment still requires selection equality,
current eligibility and a separate publish confirmation; M4.5/M4.6 own upload/viewer.
Export selection and approval remain ephemeral/empty-first across sessions, unlike
private edits. Sheet return never claims recipient delivery or recallable copies.
