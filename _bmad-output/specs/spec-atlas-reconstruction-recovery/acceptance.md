## Comparison and release gates

- **Local engine.** Freeze baseline, candidate policy, input identity, case
  labels and measurement plan before held-out scoring. Count false merges,
  false splits, false trips, missed trips, abstention, suggestion precision
  and owner actions separately. Include true cross-border and same-country
  continuity, Home/routine and existing correction controls. Require fewer
  reviewed false merges in the target cases and no regression in the holdout's
  false merges, false splits, false trips or nearby-trip recall. Protect owner
  facts, privacy and Replay scope. Insufficient or ambiguous labels leave the
  policy in shadow mode.
- **Scale and readback.** Measure full comparison time, peak resource use,
  responsiveness and cancellation on a supported device. Select and freeze
  budgets before acceptance. Exceeding a budget returns a truthful bounded
  outcome and cannot stand in for a completed comparison on the target
  library. Preserve the authorized previous generation and exact media.
- **Visual AI.** Use reviewed examples covering both recognizable and generic
  scenes. Track landmark accuracy, false capture-location suggestions,
  trip and album precision and recall, supported stop/day coverage,
  abstention, owner effort, latency and peak memory separately. Compare with
  the repaired Local engine on the same cases.
  Freeze acceptance thresholds and device budgets before holdout scoring.
  The offline slice keeps owner photos and derived recognition inputs
  on-device. A single landmark identification cannot pass the trip-recovery
  gate. A failed AI gate leaves Local repair eligible to ship.
- **Vietnamese labels.** Compare country-only fallback and supported
  city/province coverage on independent geographic controls across regions
  and historical periods. Measure wrong confident labels separately from
  fallback coverage. Block release for regressed correct titles on the
  reviewed suite or for mislabeling the Sa Đéc/Cần Thơ or Huế controls.

Run focused engine, Timeline, Home search, resolver, media, correction and
Replay tests plus actual SQLite fixtures. Run mobile TypeScript, lint, affected
bundles and `npm run check`. For engine or AI changes attach the evaluation
plan, executed evidence, version and measured limitations. For any applicable
shared-domain or storage change, run generated-domain and affected worker
checks. A green host suite does not replace Android/iOS acceptance.
